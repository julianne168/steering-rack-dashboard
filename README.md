# 转向器驾驶舱 · GitHub Pages 发布包

此发布包仅包含静态工作台页面、data.js 和页面可打开的分析结果文件；不包含脚本、原始数据、环境变量或任何凭据。

## 发布前确认

本包含有真实业务数据。普通 GitHub Pages 站点通常可被公开访问；仅在数据允许公开时才推送到公开仓库。

## 发布步骤

1. 在 GitHub 新建一个空仓库，并将本目录全部内容上传到仓库根目录。
2. 推送到 main 分支。
3. 在仓库的 **Settings → Pages** 中，将 Source 选择为 **GitHub Actions**。
4. 等待名为“Deploy GitHub Pages”的工作流完成。
5. 在 **Settings → Pages** 中复制发布链接。

首页会自动进入 06_工作台/dist/dashboard.html。分析结果文件保持在 04_分析结果/，因此模块页中的“打开完整结果”链接可以正常工作。

## 更新数据

更新时请替换以下两部分并重新推送：

- 06_工作台/dist/data.js
- 04_分析结果/ 内页面引用的结果文件

不要把 .env、03_原数据/、分析运行脚本或任何访问凭据提交到该仓库。
